# mixed-demo-v1

这是公开演示和自动化测试使用的固定混合来源数据集。整个决策数据集的
`sourceKind` 为 `MIXED`，不得解释成真实平台的当前规则或实时报价。

## 数据边界

- 11 个 ISBN、书名和五类规则形状来自用户在 2026-08-09 提供的人工观察快照。
- `platform-a` 至 `platform-e` 是求解和用户 CSV 使用的稳定代号，原始数据文件仍保存平台 A-E 别名。
- API 默认以 `real` 模式展示经人工记录核对的文字名称；可通过 `PLATFORM_DISPLAY_MODE=alias`
  切回平台 A-E，旧配置值 `observed` 等同于 `real`。两种模式都不使用第三方 Logo 或品牌图形。
- 平台名称、拒收条件、复本说明、采集日期和来源引用保存在独立的
  `datasets/platform-rule-metadata.json`，不改变本数据集及 Flyway V2 的不可变校验。
- 报价、接收状态、拒收原因和逐书复本覆盖为固定合成数据，不复用人工观察报价。
- 观察规则可能随平台、地区、账号或活动变化，本数据集不能用于实际下单。
- 金额统一使用人民币分，避免浮点数参与门槛判断。
- `generationSeed` 是本固定版本的身份标记；程序加载时不应重新随机生成数据。
- `objectivePolicyVersion` 固定四阶段词典序目标，`engineVersion` 标识对应的求解实现契约。
- `disclaimers` 提供可机器读取的观察规则、合成报价、非实时报价和非最终结算提示；单字符串
  `disclaimer` 仅为兼容展示保留。

## 规则覆盖

| 平台 | 订单有效条件 | 额外约束 |
| --- | --- | --- |
| 平台A | 金额至少 2000 分 | 每单最多 40 本 |
| 平台B | 金额至少 4800 分，或至少 8 本 | 无额外本数上限 |
| 平台C | 金额至少 1000 分 | 同一 ISBN 每单最多 1 本 |
| 平台D | 金额至少 3990 分，或至少 10 本 | 无额外本数上限 |
| 平台E | 金额至少 3800 分，或至少 10 本且均价至少 150 分 | 均价约束以 `总金额 >= 本数 × 150` 计算 |

`ruleSummary` 是可直接返回给前端的短文案；结构化的 `threshold` 才是求解器的
事实来源。`UNKNOWN` 与 `REJECTED` 报价的 `unitPriceCents` 都必须为 0，并且
不能进入订单。

## 默认样例的预期性质

`suggestedInventory` 为每种书 1 本。按“售出本数、预估金额、使用平台数、订单数”
依次优化时，设计目标为：

1. 11 本全部售出；
2. 预估总金额为 6659 分；
3. 使用平台 A 和平台 C，共 2 个有效订单；
4. 平台 A 接收 ISBN `9787020002207`、`9787111544937`、`9787508647357`、
   `9787040396638`、`9787040599008`、`9787040599015`，合计 3936 分；
5. 平台 C 接收其余 5 本，合计 2723 分。

没有任何单一平台接收全部 11 种书，因此这个默认输入能直接展示跨平台组合的核心
价值。平台 B、D、E 的完整接收集合还分别提供“8 本”“10 本”和“10 本且均价”
分支的门槛样例。

## 复本策略

- `INHERIT_PLATFORM`：继承平台的 `defaultRepeatPolicy`。
- `ONE_PER_ORDER`：同一 ISBN 在一个订单中最多 1 本。
- `UP_TO_INVENTORY`：不添加额外复本上限，但仍受用户库存数量约束。
